每日流程

每次練習都照這個順序走，讓多個 AI 分工更穩。

20-40 分鐘流程

  • 選一個很小的功能，例如新增一張成果卡、改善搜尋、做一個表單。
  • 先請一個 AI 幫你拆需求，再請另一個 AI 產出 UI 或文字。
  • 交給 Codex 實作、測試、推到 GitHub Pages。
  • 把今天學到的 prompt 寫進成果區。
